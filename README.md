# 榆桥社区口述史馆折页编印工作台

工作台供访谈整理员、编辑、排版员、两个印席和装订员使用。听众可凭固定册号查阅已成册的引文。运行需要 Python 3.11，网页使用原生 HTML 表单，状态保存在本地 SQLite。

```sh
python3 -B -m desk.http --db workbench.sqlite3 --port 8000
```

在浏览器打开 `http://127.0.0.1:8000/`。首次启动登记样例册 `yuqiao-01` 及左右印席。后续启动保留数据库内的修订、纸单、实印与成册记录。保存纸单网页可继续使用其中的提交地址，重启后请沿用原端口。

## 一天的编印工作

1. 整理员准备访问引文。`samples/yuqiao.json` 给出样例正文，左席负责 A，右席负责 B。
2. 编辑录入页格稿。每行依次为引文键、逗号分隔的正整数页号、正文，三栏用制表符隔开。例如 `A`、`2,3`、`过河先听铃。`。依次录入 A 的 `2,3`，B 的 `4,5`，C 的 `1`。
3. 排版员用修订号试排。可以额外指定引文页号，每行用制表符分隔引文键和页号。一个页格最多放一段，允许跳页。冲突时页面给出原因。编辑发布首稿后印席即可领单。
4. 左右印席分别打开原纸单并保存网页。选项编号在本单内有效。重开席位页面返回本轮原单。暂时没有相容选项时，仍可稍后领取。
5. 编辑保存并尝试发布仅允许 A 在第 3 页的勘误。两席仍待报时，该稿无法兑现左席已经领出的 A→2，原稿继续有效。
6. 左席从原纸单报 A→3。网页显示本次实印归属及页码。同项重试复领原结果，异项重提保留首次实印。编辑重提勘误时，两种右席选项仍可兑现，勘误获准。
7. 右席从原单报 B→5。装订员请求成册后，固定页包含 A→3、B→5 及普通引文 C。
8. 听众和装订员凭固定册号查正文与实印索引。编辑可以在上一轮固定后为同一册发布下一轮首稿，旧册仍可依原号读取。

## HTTP 接口

默认响应为 HTML。请求头 `Accept: application/json` 可取得对应的结构化结果。POST 使用 `application/x-www-form-urlencoded`。表中的字段各提交一次，选填字段可省略。

| 方法和路径 | 字段 | 成功结果 |
| --- | --- | --- |
| `POST /revise` | `book`、`quotes`，其中 `quotes` 为上文的制表符稿件 | `revision` |
| `GET /preview` | `book`、`revision`、选填 `pins` | `pages` 为引文键到页号的映射 |
| `GET /sheet` | `book`、`seat`，席位取 `left` 或 `right` | `sheet`、`round`、`options`，表单含原单值 |
| `POST /return` | `book`、`seat`、`sheet`、`option`，取自原网页 | `status` 和含册、席、原单、选项、页码的 `actual` |
| `POST /amend` | `book`、`revision` | `accepted`、`current`、`round` |
| `POST /bind` | `book` | `edition`、`revision`、`round`、固定正文与实印索引 |
| `GET /read` | `id` 为固定册号 | 按数值页号排序的 `pages`、两席 `citations`、核对结果 `verified` |

非法页格或表单字段返回 400，未知册、席、修订或固定册返回 404。试排不可行、暂无可发选项、实印不匹配、改版不可兑现或尚未报齐返回 409。试排冲突返回空的 `pages` 值和 `reason`，改版拒绝返回仍有效的 `current` 及首个失败组合。报回的 `actual` 在接纳、同项重提或改报被拒时反映已经落账的首次实印；错误归属不返回实印详情。试排允许空稿或跳页，空稿不能发出纸单选项。各请求的成功结果在事务结束后返回。

## 核验和演示

```sh
python3 -B check_project.py
python3 -B -m unittest -v tests.test_binding.BindingTests.test_print_to_bound_copy
```

核验入口由运行环境提供，执行 `tests` 包的完整回归。演示在独立临时数据库和本机随机端口运行，显示改版裁决、旧表单报回及最终成册的实测页码。回归和演示均在业务断言失败时非零退出。
